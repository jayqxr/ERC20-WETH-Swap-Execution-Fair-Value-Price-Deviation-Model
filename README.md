# ERC20-WETH-Swap-Execution-Fair-Value-Price-Deviation-Model
### ERC20/WETH Swap Pressure Model   This script decodes swap logs from a UniswapV3 pool, computes real execution prices, compares them to Dexscreener fair value, and measures price deviation to quantify buy/sell pressure.   Final visualizations show execution impact, token flows, and USD flows.
